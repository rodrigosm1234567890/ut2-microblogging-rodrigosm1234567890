# Mi bitácora — TIC II · UT2 Microblogging

Este repositorio es tu **bitácora**: un microblog personal hecho con HTML y CSS, que se publica automáticamente en GitHub Pages cada vez que haces `push`.

**Tu bitácora publicada:** `https://iesviadelaplata-tic2-2026.github.io/NOMBRE-DE-ESTE-REPOSITORIO/`

> Tarda uno o dos minutos en actualizarse después de cada `push`.

## Estructura

```text
README.md            ← este archivo
index.html           ← tu bitácora: un <article class="post"> por cada post
css/estilos.css      ← estilos (personaliza los colores)
img/                 ← tus imágenes (borra ejemplo.svg cuando ya no la uses)
ejercicios/          ← ejercicios 1 a 5 de las prácticas, en Markdown
```

## Normas

Este repositorio y la web publicada son **públicos**: cualquiera puede verlos.

- Firma con un **alias**, nunca con tu nombre y apellidos.
- No publiques **datos personales** tuyos ni de otras personas: dirección, teléfono, horarios, ubicación…
- No publiques **fotos de otras personas** sin su permiso.
- Usa solo imágenes, vídeos y música **propios** o con una **licencia que lo permita**, y cita siempre al autor y la licencia.
- Todas las imágenes llevan **texto alternativo** (`alt`).
